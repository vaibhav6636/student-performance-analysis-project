# Student Performance Analysis Project

## Overview
This research project analyzes the academic performance, personal challenges, and environmental factors affecting undergraduate students using statistical analysis and machine learning techniques.

The study was conducted using primary survey data collected from undergraduate students in Kolhapur District.

---

## Objectives

- Identify factors affecting academic performance
- Analyze student challenges and difficulties
- Study relationships between study habits and achievement
- Identify at-risk students using machine learning models

## Key Findings

- Internal performance strongly affects academic achievement
- Backlogs negatively influence student performance
- Students face moderate academic and personal challenges
- Time management and counselling are major support needs
- Logistic Regression performed best for at-risk student prediction

---

## Conclusion

This project demonstrates how statistical analysis and machine learning techniques can help understand student challenges, predict academic risk, and support educational decision-making.
